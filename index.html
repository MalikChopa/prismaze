      Comment jouer

      Guide le faisceau jusqu'aux cibles.

      1. 1Toucher : tourner

        Clic droit ou appui long : l'autre sens

      2. 2Glisser : déplacer

        Sur une case libre

      3. 3Allumer toutes les cibles

        Moins de pièces, plus d'étoiles

      Au clavier : flèches pour choisir une case, Entrée pour prendre puis poser une pièce, R pour la tourner, Échap pour revenir.

        À propos

        Un jeu de réflexion : plie la lumière avec des miroirs, des filtres et des prismes. 50 niveaux, un défi par jour, un éditeur.

        Version

        Logiciel libre, licence GPL-3.0. Code source : github.com/MalikChopa/prismaze

        Rien n'est envoyé : ta progression reste dans ton navigateur.

        Fabriqué en JavaScript, Canvas, WebGL et Web Audio, sans bibliothèque, sans police ni image téléchargée.
